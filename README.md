# spike-portfolio

Personal portfolio for **Prathamesh Bhujbal** (Spike / Pratham), built with
[Astro](https://astro.build). The look and feel is a hand-written port of the
[Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll
theme (the "air light" colour scheme, system font stack, fixed left sidebar,
greedy top navigation and pinned footer).

Live site: <https://psb-001.github.io/spike-portfolio/>

## Everything editable lives in one file

`src/config/site.ts` is the single source of truth. Change the bio, social links,
projects, skills, education, the masthead nav or what you're currently watching
there — **no component code needs to be touched**.

```ts
// src/config/site.ts
export const siteConfig = {
  name: "Prathamesh Bhujbal",
  aka: ["Spike", "Pratham"],
  bio: "...",
  social: [{ network: "github", label: "GitHub", url: "https://github.com/psb-001" }],
  currentlyWatching: { tmdbId: 1399, type: "tv" },
  projects: [{ name: "minimaldoro", description: "...", tech: ["Svelte"], url: "..." }],
};
```

## "Now watching" (TMDB)

The poster is fetched **at build time** by `scripts/fetch-movie.mjs`, which reads
the TMDB id and type from `src/config/site.ts` and writes
`src/data/now-watching.json`. The API key lives only in the build environment —
it is never committed and never reaches the browser. The poster image itself is
downloaded into `public/posters/` so the deployed site does not hot-link TMDB.

To change what you're watching, edit `currentlyWatching` in the config:

```ts
currentlyWatching: {
  tmdbId: 550,   // Fight Club
  type: "movie", // or "tv"
},
```

Get a free key at <https://www.themoviedb.org/settings/api>. Both a v3 API key
and a v4 read access token work.

Locally:

```bash
cp .env.example .env   # then put your key in .env
```

In CI, add the same value as a repository secret named `TMDB_API_KEY`.

> Without a key the build still succeeds — it keeps the last fetched data (or the
> committed placeholder) and renders the widget's placeholder state.

This product uses the TMDB API but is not endorsed or certified by TMDB.

## Local development

```bash
npm install
npm run dev          # http://localhost:4321/spike-portfolio/
npm run build        # runs the TMDB fetch first, then astro build
npm run preview      # serve ./dist
npm run check        # astro check (TypeScript + Astro diagnostics)
```

The site is built for a GitHub Pages sub-path, so every link is prefixed with
`/spike-portfolio`. To preview it at a domain root, build with
`BASE_PATH=/ SITE_URL=http://localhost:4321 npm run build`.

## Deployment

Pushes to `master` (the default branch) run `.github/workflows/deploy.yml`,
which builds the site and publishes `dist/` to the `gh-pages` branch with
[peaceiris/actions-gh-pages](https://github.com/peaceiris/actions-gh-pages).

Repository secrets required:

- `TMDB_API_KEY` — enables the poster fetch (optional; the build succeeds without it).

If Pages is configured for the Actions source instead, set "Deploy to a GitHub
Pages" in **Settings → Pages**; otherwise the `gh-pages` branch is enough.

## Project structure

```
src/
├── config/site.ts          # ← the single source of truth for all content
├── components/             # Icon, Nav, Sidebar, ProjectCard, NowWatching
├── layouts/Base.astro      # masthead + sidebar + footer shell
├── pages/                  # index, projects, about, 404
├── styles/global.css       # hand-ported Academic Pages "air light" theme
├── data/
│   ├── now-watching.json   # generated by scripts/fetch-movie.mjs
│   └── projects.ts         # typed view over siteConfig.projects
└── utils/url.ts            # base-path aware link helper
scripts/fetch-movie.mjs     # build-time TMDB fetch
public/                     # profile.jpg, favicon, generated posters
```

## Design notes

The Academic Pages Sass has been flattened to plain CSS in
`src/styles/global.css`, keeping the original values:

| Theme variable       | Value                                  |
| -------------------- | -------------------------------------- |
| `--global-base-color`   | `#0092ca` (air light primary)        |
| `--global-bg-color`     | `#eeeeee`                            |
| `--global-text-color`   | `#222831`                            |
| `--global-link-color`   | `#393e46`                            |
| `--global-border-color` | `#004965` (`mix(#000, #0092ca, 50%)`) |
| `--border-radius`       | `4px`                                |
| `--box-shadow`          | `0 1px 1px rgba(0, 0, 0, 0.125)`     |
| masthead height        | `70px`                                |
| fixed sidebar from     | `1024px`                              |

Susy's 12-column fluid grid is expressed as the equivalent `calc()` widths
(sidebar `span(2 of 12)`, page `span(10 of 12 last)` with a `0.5 of 12` prefix).

Placeholders to replace when details land: the DRDODIAT internship description
and the project summaries for repos that had no description on GitHub.
